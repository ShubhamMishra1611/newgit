=== 2. nonlinear relations for IST: residual as function of lambda^2 (kappa^2=1) ===
  O(s7):  k2 g3 = g0^2/2                     residual = -lambda2*(lambda2 - 2)/2
  O(s9):  k2 g5 = g2 g0                      residual = -lambda2*(lambda2 - 2)/2
  O(s10): k4 g6' = 8/3 k4 g6 + g0^3/6        residual = -lambda2*(lambda2 - 2)*(lambda2 + 2)/6
  O(s11): k2 g7 = g4 g0 + g2^2/2             residual = -3*lambda2*(lambda2 - 2)/8
  O(s12): k4 g8' = 8 k4 g8 + g2 g0^2/2       residual = -lambda2*(lambda2 - 2)*(lambda2 + 2)/4
  O(s13): k2 g9 = g6 g0 + g4 g2              residual = -lambda2*(lambda2 - 2)/4
  O(s13): k6 g9' = 8/3 k4 g6 g0 + g0^4/24    residual = -lambda2*(lambda2 - 2)*(lambda2**2 + 2*lambda2 + 12)/24
  -> every residual vanishes at lambda^2 = 2 (=2 kappa^2), cf. 2607.14230 text after (5.13)
